# TensorTopology - Professional IT Infrastructure Solutions

A modern, responsive website for TensorTopology showcasing IT infrastructure, AI/ML, networking, and cloud solutions.

## 🚀 Features

- **43+ Pages** covering all IT services
- **Responsive Design** - Mobile, tablet, and desktop optimized
- **Hero Carousel** with background images
- **Dark Navigation** with dropdown menus
- **Contact Form** with Gmail SMTP integration
- **Animated Stats Section**
- **Service Categories**: AI/ML, Networking, Infrastructure, Cloud, Security

## 🛠️ Tech Stack

- **Next.js 15** - React framework
- **TypeScript** - Type safety
- **Tailwind CSS** - Styling
- **Nodemailer** - Email functionality
- **Lucide Icons** - Modern icon set

## 📧 Contact Form

The contact form uses Gmail SMTP to send emails directly to tensortopology@gmail.com.

**Email Capacity**: 500 emails per day (free Gmail SMTP limit)

## 🌐 Deployment

Deployed on **Vercel** for optimal Next.js performance.
